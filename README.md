# 🌙 NightNote

> **Remember Tonight. Accomplish Tomorrow.**

NightNote is an AI-powered productivity companion that transforms your late-night thoughts into a structured, prioritized action plan for the next day. Simply dump your thoughts before sleeping, and let AI organize them into an achievable mission.

---

## ✨ Features

- 🌙 Night Brain Dump (Text & Voice)
- 🤖 AI-Powered Mission Generation using Groq AI
- 🎯 Intelligent Task Prioritization
- ✂️ Smart Trim to reduce task overload
- ✅ Interactive Task Completion
- 📊 Progress Dashboard
- 🔥 Daily Streak Tracking
- 📈 Weekly Productivity Summary
- 🌗 Light & Dark Theme
- 💾 Local Data Persistence
- 📱 Android Ready (Capacitor)

# 🧠 How It Works

### 1️⃣ Dump Your Thoughts

Write or speak everything you want to remember before sleeping.

Example:

> Finish DBMS assignment, solve 2 LeetCode problems, call mom, revise DAA.

---

### 2️⃣ AI Understands Everything

Groq AI analyzes your note.

It automatically:

- extracts tasks
- estimates effort
- understands urgency
- assigns priorities
- creates tomorrow's mission

---

### 3️⃣ Morning Dashboard

Wake up to an organized mission.

Features:

- Priority Tasks
- Estimated Time
- Completion Tracking
- Smart Trim
- Progress

---

### 4️⃣ Smart Trim

Feeling overwhelmed?

Smart Trim asks Groq AI to optimize your day by

- reducing overload
- postponing low-value work
- keeping important tasks
- balancing workload

---

### 5️⃣ Track Your Progress

NightNote automatically tracks

- Tasks Completed
- Daily Streak
- Weekly Summary
- Productivity Insights

# ⚙️ Installation

Clone the repository

```bash
git clone YOUR_REPOSITORY_LINK
```

Move into the project

```bash
cd NightNote
```

Install dependencies

```bash
npm install
```

Start development server

```bash
npm run dev
```

---

# 📱 Android Build

Build the web app

```bash
npm run build
```

Sync Capacitor

```bash
npx cap sync
```

Open Android Studio

```bash
npx cap open android
```

Generate APK from Android Studio.
